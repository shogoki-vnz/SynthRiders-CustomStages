# SynthRiders Custom Stages and Experiences

Unity Project template that helps make Custom Stages and Experiences for [Synth Riders](https://synthridersvr.com/)

As of version ``0.5``, This template uses the Unity Version ``6000.3.13f1`` and is compatible with Synth Riders version ``3.6.5`` and later.


Ver ``0.5`` is a major release of the template and the documentation is pending, please go to [Our Discord](https://discord.gg/synthriders) for Support and Information in the interim.
